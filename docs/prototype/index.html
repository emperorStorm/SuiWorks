03 / ABOUT

一个人的
软件工坊

“先把东西做出来，再把它做久一点。”

岁序工坊是一个人的软件工坊。这里收录我自己在用的桌面工具、移动应用与 Web 服务，它们大多从一个具体的小问题开始，然后被慢慢打磨成可以长期使用的东西。

我偏爱本地优先：数据先留在自己的设备上，网络与云服务是补充，而不是前提。

  • 01
    本地优先

    能离线完成的事，就不依赖服务器；数据默认放在自己的设备里。

  • 02
    一物一用

    每个工具解决一类问题，不把所有能力塞进同一个入口。

  • 03
    长期维护

    先把东西做出来，再持续修正，让它经得起日常使用。

TECH / 正式版规划

Vue 3 · TypeScript · Vite SSG · Nginx

当前页面是静态 HTML 原型；正式项目已采用构建期预渲染的纯静态架构，生产服务器只运行 Nginx。
