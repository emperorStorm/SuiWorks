02 / HOST

单机部署拓扑

服务器只需 Nginx 与静态文件；没有业务服务、数据库端口或 Redis 端口。

阿里云 ECS · Alibaba Cloud Linux 32 vCPU / 1.8 GiB / 40 GiB
nginx :80 / :443HTTP 跳 HTTPS · TLS · 静态托管常驻约 12–20 MB
/opt/suiworks/current当前版本 HTML、资源与页面磁盘按实际素材规划

发布与回滚

  1. 本机构建并检查 SSG不在 ECS 构建
  2. rsync 到新版本目录旧版保留
  3. 原子切换 current发布切换
  4. nginx -t 后 reload不中断旧进程
  5. HTTPS 探活与抽查首页 / 详情
回滚时将 current 切回上一版本，再检查配置并 reload Nginx；保留最近 3 个版本。

04 / TRADEOFF

方案边界与扩展

只有出现服务端状态或写入需求时，才增加后端与数据库。

需求纯静态是否满足后续扩展方向
作品展示、分类筛选、详情满足保持静态数据与构建流程
下载到各作品的安装包满足GitHub Releases 或 OSS
浏览器在线修改内容不满足轻量管理 API + 持久化存储
账号与跨设备数据同步不满足HTTPS API + 服务端数据库；客户端按需 SQLite / IndexedDB
下载统计、留言等动态功能不满足按真实规模选服务端方案；初期不预装 Redis
当前结论

作品站只读展示，Vue + Vite SSG + Nginx 即可；不需要 Java、Node API、MySQL 或 Redis。

内容更新

修改数据文件后重新构建并发布；代码仓库负责版本管理，不必维护内容数据库。

多端数据

未来有用户数据同步时，各端通过 API 访问服务端数据库，不让客户端直接连接 MySQL。
